🎧 Spotify Music Analysis & Insights

📌 Overview
This project focuses on analyzing Spotify music data to uncover trends, patterns, and insights about songs, artists, and user listening behavior. The goal is to transform raw music data into meaningful insights using data analysis techniques.

 

🎯 Objectives
- Understand trends in music popularity
- Analyze relationships between audio features
- Identify top-performing artists and tracks
- Explore how features like tempo, energy, and danceability impact popularity

 

📊 Dataset
The dataset contains Spotify track-level data including:
- Track name
- Artist
- Popularity
- Tempo
- Energy
- Danceability
- Loudness
- Duration
Dataset Link: https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset

🛠️ Tools & Technologies
- Python 🐍
- Pandas
- NumPy
- Matplotlib & Seaborn
- Jupyter Notebook

 
🔍 Key Steps

 1. Data Loading
- Imported dataset using Pandas
- Inspected structure and data types

 2. Data Cleaning
- Removed missing/null values
- Fixed inconsistent data types
- Handled duplicate records

 3. Exploratory Data Analysis (EDA)
- Distribution of popularity
- Correlation between audio features
- Artist-level analysis
- Feature impact on hit songs

 4. Visualization
- Heatmaps for correlation
- Histograms & boxplots
- Trend analysis graphs

 
📈 Key Insights
- High energy and danceability are strongly linked with popular tracks
- Some artists consistently dominate popularity rankings
- Tempo and loudness show moderate correlation with listener engagement
- Not all highly energetic songs are popular — balance matters

 

 🚀 Future Improvements
- Build a recommendation system
- Apply machine learning for popularity prediction

📌 Conclusion
This project demonstrates how raw music data can be transformed into actionable insights using data analysis. It highlights the importance of feature relationships in determining music popularity.
