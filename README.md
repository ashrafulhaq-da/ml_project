🎧 Spotify Music Analysis
📌 Overview

This project analyzes Spotify music data to uncover patterns and insights related to song popularity and audio features. It demonstrates a complete data analysis workflow, including data cleaning, exploration, visualization, and interpretation.

The objective is to understand how musical attributes such as tempo, energy, and duration influence the popularity of songs.

🎯 Objectives
Clean and preprocess the raw dataset
Perform exploratory data analysis (EDA)
Analyze relationships between audio features
Visualize trends and patterns
Extract meaningful insights from data

🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
 

📊 Analysis Performed
Data cleaning and preprocessing
Handling missing values
Statistical summary of dataset
Feature correlation analysis
Visualization of key attributes
Trend analysis of song popularity

📈 Key Insights
Popular songs tend to fall within specific ranges of tempo and energy
Certain audio features show noticeable correlation with popularity
Most songs follow a consistent duration pattern
Data reveals underlying trends in modern music preferences
