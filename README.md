# ml_project
📊 Spotify Music Analysis & Prediction
📌 Project Overview

This project focuses on analyzing Spotify music data to understand the factors that contribute to a song's popularity and to predict whether a song is trending using machine learning models.

🎯 Objectives
Perform data cleaning and preprocessing
Conduct exploratory data analysis (EDA)
Build classification models to predict trending songs
Apply clustering to discover hidden patterns in the dataset
🗂️ Dataset

The dataset contains various audio features of songs such as:

Energy
Danceability
Loudness
Tempo
Valence
Popularity
⚙️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
🔍 Exploratory Data Analysis (EDA)
Checked missing values and handled them
Analyzed distributions of features
Visualized relationships between variables
Identified key features influencing popularity
🧠 Machine Learning Models

The following models were implemented:

Logistic Regression
Decision Tree Classifier
Random Forest Classifier
✅ Evaluation Metrics:
Accuracy Score
Classification Report (Precision, Recall, F1-score)
📊 Clustering
Applied K-Means Clustering to group songs based on audio features
Identified patterns and similarities among different types of songs
📈 Key Insights
High energy and danceability are strongly correlated with trending songs
Some features have greater influence on prediction than others
Songs can be grouped into distinct clusters based on audio characteristics
